> 繼電器控制實驗枱（非 PLC）。本文整理本專案從空白倉庫到目前的產品、架構與操作，方便之後接續開發。

最後更新：2026-08-21

## 1. 產品定位

在瀏覽器裡畫**硬接線繼電器／接觸器控制圖**（二次回路梯形圖 + 一次回路），可模擬運行，並用粒子顯示**電流由 L 流向 N**。

- **做：** 電工繼電器–接觸器控制（SB、KM、FR、KT、電機、起動器）
- **不做：** PLC（IEC 61131-3 LD、廠牌指令）
- 符號可切 **NEMA／JIC（美）** 或 **IEC／GB（歐／國標）**；預設 NEMA

教學核心電路：啟動／停止自鎖、正反轉互鎖、星三角、選擇開關定轉向。

## 4. 資料模型（重點）

電路是 **graph**，不是圖片。

- `Device`：一個物理裝置（KM1 線圈與觸點共用 id）
- `SymbolInst`：畫布上的一個符號（coil / main / aux-no / aux-nc）
  - `rot`：0 / 90 / 180 / 270
  - `flipX` / `flipY`：本地鏡像（UI 的左右／上下是畫面方向，旋轉後會對應到正確的本地軸）
- `Wire`：接兩個 `{ symbolId, term }`；可 `broken`、可 `jog`（中段拖動）
- `SymbolGroup`：`circuit.groups[]`，每個組有 `memberIds`；一個符號最多屬一組（再成組會合併）
- 端子世界座標：`applyFlip` → `rotatePoint` → `variantDef`

特殊裝置：

| kind | 用途 |
|---|---|
| `net-label` | 標籤端子。相同 `tag`（trim 後、區分大小寫）的 pin `"1"` 在模擬裡 union 成同一點。空白標籤不連通。**不會**因為叫 L1 就自動接到電源 L1 腳。 |
| `junction` | T 接產生的連接點。不出現在元件庫。無走線 stub。兩條腿時刪除會把線接回一條。 |

模擬：節點電位（L1/L2/L3/N/DC+/DC-）+ 導通網路（閉合觸點當導線）。**不是 SPICE。**

負載得電：兩端分別接到相容電位（例如 L1 與 N）。三相電機看 U/V/W 相序；六端子時可判星形／三角。

接觸器觸點比線圈遲一個掃描週期（用上一拍 `energized`），自鎖／互鎖才正確。

## 5. 已實現功能（對應對話）

### 編輯

- 元件庫點選 → 圖紙放置；可連續放
- **Esc 或右鍵** 取消放置／取消拉線，返回選擇
- 端子對端子接線；一般端子先 **直線引出 2 格** 才允許 90° 拐彎
- **標籤端子、連接點不引出 stub**
- 拉線途中可點在**導線任意位置**做 T 接（產生可拖動的圓點）；點圓點可再拉線
- **標籤端子**（I/O）：同名即通路。連續放置／複製沿用同一個標籤。H 鏡像可把旗標掛另一邊
- 導線可點擊、拖中段（橫線上下、豎線左右），存 `wire.jog`
- 選中：**R** 順時針、**Shift+R** 逆時針、**H** 左右鏡像、**V** 上下鏡像（標籤文字保持正向）
- 空白處**拖框**框選（Shift 加選）；Shift 點選
- 多選可整組拖動（每件用自己的原點，唔好共用被點嗰件座標）
- **⌘G** 編成一組：之後點其中一件即選全組；拖動／旋轉／鏡像／複製／刪除都係整組。藍虛線框
- **⇧⌘G** 打散。複製貼上會保留編組
- ⌘C / ⌘V / ⌘D / ⌘A；Delete；方向鍵微移
- 空白圖紙**不**自動放三相電源

### 符號（NEMA／JIC，對齊美國課本梯形圖）

- 觸點：兩條豎線 `‖`，左右各直出 **1 格**才到端子；預設橫放（KM NO／NC、KA、限位等同款）
- PB NO：倒 T（⊥）與兩圓端子之間有空隙；按下有柱塞動畫
- PB NC：兩圓端子坐在倒 T 橫桿上，直杆向上
- 線圈：圓圈；指示燈：芒線圓
- 實心元件（三相電源等）編輯模式游標為 **grab**，與 PB 一致（符號內部 `cursor: inherit`）
- IEC／GB 仍可切換

### 模擬與電流

- 運行／暫停／單步／復位
- 粒子方向統一 **L（L1/L2/L3/DC+）→ 負載 → N（N/DC-）**
- 即使導線畫反（先接 N），動畫仍朝 N 流
- 實物檯：按鈕、燈、馬達、斷路器、熱繼電
- 過程量：液位、限位驅動感測器
- 故障：斷線、觸點熔死（主觸點熔死後停掣斷唔到馬達）
- 標籤端子／連接點得電時會變色（有電位）

### 例題

| id | 名稱 |
|---|---|
| lamp | 指示燈點動 |
| dol | 接觸器自鎖起動 |
| rev | 正反轉點動 |
| yd | 星三角降壓起動 |
| selrev | 選擇開關正反轉（Figure 15-23 類） |

### 存檔

- 本機圖庫、匯出／開啟 JSON、`#c=` 分享連結
- 自動草稿 `localStorage`
- 載入時 `sanitizeCircuitIds`：重複 id 會改名；補 `groups: []`

## 6. 模擬規則速記

- 掃描約 50 ms；計時器用模擬時間，勿用 `setTimeout`
- 停止鈕是 **NC**：沒按時導通
- 正反轉組合起動器兩線圈同時得電 → 機械互鎖，狀態列警告
- 星三角：KM1 線路、KM2 星、KM3 三角；KT 15–16 未到時、15–18 到時
- 控制回路美國例用 L1–L2，不是一定 L1–N

電流方向算法：

1. 導通圖 = 未斷線的導線 + 閉合內部橋 + 同標籤端子（`net-label`）+ 連接點（同一 pin 多條線）
2. 從電源熱端（L1/L2/L3/DC+、變壓器 S1）BFS
3. 從回流端（N/DC-、變壓器 S2）BFS
4. 熱網：離 L 近 → 離 L 遠（流向負載）
5. 回流網：離 N 遠 → 離 N 近（流向 N）
6. `WireLive.dir === -1` 時粒子沿反向 path 走

## 7. 元件庫（節錄）

電源保護：三相電源、控制變壓器、1P/3P 斷路器、熔斷器、隔離開關、熱繼電器 FR  
接線：標籤端子（同名即導通）；連接點由 T 接自動產生，不在庫裡  
開關：PB NO/NC、急停、選擇 2 檔／正停反、撥動、腳踏  
感測：限位、液位、溫度、壓力、流量、接近、光電  
控制：接觸器（線圈／主觸點／NO／NC）、中間繼電器、TON／TOF、計數器  
負載：燈、報警、電笛、風扇、電熱、電磁閥  
電機：3Φ／1Φ／DC、AC／DC 發電機  
起動器：DOL、正轉、反轉、正反轉組合

接觸器是「一裝置多符號」。Palette 的 KM NO 是 `creates: "attach"`，掛到已選或最後一個 KM。

## 9. UX 細節（踩過的坑）

- SVG 空白處 CSS 格線**不可點**，必須有透明 `rect` 命中層
- 放置模式要再加一層 overlay，否則點在舊導線上會取消放置
- 右鍵在放置模式必須 `button !== 0` 才放置，否則會誤放一個再取消
- `R`／`H`／`V` 要 `toLowerCase()`，輸入框內唔好觸發
- 端子若畫在符號邊緣，走線 90° 會疊元件 → 觸點左右先直出 1 格，走線再 stub 2 格；標籤端子／連接點無 stub
- 實心符號（三相電源）蓋住 `.sym-hit` → 游標變成紙張的十字。`.sym-g * { cursor: inherit }` 先至係 grab
- **複製撞 id：** 舊 `uid` 係 `d_2` 這類計數器。重新載入草稿後 seq 從 1 再數，複製會重用已有 id，`.find` 綁到三相電源／SB，React key 重複整張圖亂。而家 uid 帶隨機後綴，貼上前檢查已用 id，載入時 sanitize
- 多選拖動必須用**每件自己的** `s.x/s.y` 做 origin，唔可以全部寫成被點嗰件嘅座標
- 全選後再點已選中的一件：mousedown 保留多選以便拖動；mouseup 無拖先至收斂成嗰一件（若已成組則收斂成嗰一組）

## 12. 對話裡拍板的決策

1. 先做繼電器控制，不做 PLC  
2. 圖是 graph  
3. 二值導通 + 觸點遲一拍  
4. 美式符號跟 NEMA／JIC 課本（倒 T 按鈕、‖ 觸點、圓圈線圈）  
5. 空白圖紙不預放電源  
6. 電流動畫統一 L→N，與導線繪製方向無關  
7. 遠距接線用標籤端子，同名即通路，不靠名稱自動接到電源引腳  
8. 長線／多線匯合用 T 接連接點，交點可拖  
9. 觸點引出 1 格（不是 2 格）；標籤端子無 stub  
10. 成組係扁平合併（一個符號一組）；打散一次全部獨立
